MoleMix Учебное пространство — тестовая локальная версия

КАК ОТКРЫТЬ
1. Откройте файл index.html двойным кликом в браузере.
2. Сначала откройте раздел «Ученики» и добавьте ученика.
3. Перейдите в «Календарь» и добавляйте занятия в нужные даты.

ЧТО УЖЕ РАБОТАЕТ
- календарь по месяцам и годам;
- добавление/редактирование учеников;
- у каждого ученика свой цвет и личная страница;
- цель, нынешний уровень, контакты, общая заметка;
- занятия: дата, время, цена, темы, прогресс 1–10, ДЗ, комментарий;
- статусы «проведено», «оплачено», «отменено»;
- синхронизация календаря и журнала ученика;
- подсчёт получено / ожидает оплаты / проведено;
- экспорт резервной копии JSON;
- адаптация под телефон.

ВАЖНО
Сейчас данные хранятся в localStorage конкретного браузера.
Это тестовая версия для утверждения дизайна и логики.
После утверждения интерфейса подключим Firebase, чтобы данные сохранялись в облаке и были доступны с разных устройств.
